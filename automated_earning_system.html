🚀 Quick Start - Get Running in 60 Seconds!

  1. Clone and navigate to the repository
    git clone https://github.com/S3OPS/money.git && cd money
  2. Run the quick start script
    python quick_start.py
  3. Add your Amazon Associate ID to .env file
    AMAZON_ASSOCIATE_ID=your-associate-id-20
  4. Generate your first content!
    python content_generator.py
  5. Enable automation and watch it work
    python content_generator.py --schedule
